# Balcão SNCR · edição gratuita

Site estático publicado em **https://balcao.2ducks.cloud** (GitHub Pages).

Simulador gratuito para treinar o atendimento de receitas controladas no novo SNCR da Anvisa: 7 módulos, 35 atendimentos simulados, consulta ao SNCR e feedback a cada decisão. O progresso fica no navegador de quem usa; não há cadastro nem coleta de dados.

Este repositório contém **apenas o site compilado**. Um projeto da [2Ducks EdTech](https://www.instagram.com/2ducks_tech/). Ferramenta educacional independente, sem vínculo com a Anvisa.
